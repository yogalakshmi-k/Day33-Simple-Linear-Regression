
# Day 33 - Simple Linear Regression

## Project Overview
This project implements a Simple Linear Regression model using Python and Scikit-learn to predict salary based on years of experience.

## Objective
To build and understand a supervised machine learning regression model using one numerical feature.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
Salary vs Experience Dataset

- Independent Variable: Years of Experience
- Dependent Variable: Salary

## Project Workflow
1. Imported required libraries.
2. Created and prepared the dataset.
3. Selected input and target variables.
4. Split the dataset into training and testing data.
5. Trained the Linear Regression model.
6. Generated salary predictions.
7. Evaluated model performance.
8. Visualized the regression line.

## Model Used
Linear Regression from sklearn.linear_model.

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R2 Score

## Project Files
- Day33_Simple_Linear_Regression.ipynb
- salary_dataset.csv

## Conclusion
Successfully built a Simple Linear Regression model to predict salary based on years of experience and understood the fundamentals of supervised machine learning.
